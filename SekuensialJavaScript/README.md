# 📘 Materi Pemrograman Sekuensial JavaScript

Kumpulan materi lengkap tentang **pemrograman sekuensial** di JavaScript, dengan penjelasan detail dan komentar yang jelas di setiap baris kode.

---

## 📂 Daftar Materi

| No | File | Topik | Deskripsi |
|----|------|-------|-----------|
| 1 | `01-pengenalan-sekuensial.js` | Pengenalan Sekuensial | Konsep dasar eksekusi berurutan, analogi kehidupan nyata |
| 2 | `02-variabel-dan-tipe-data.js` | Variabel & Tipe Data | var/let/const, tipe data primitif & non-primitif |
| 3 | `03-operator.js` | Operator | Aritmatika, penugasan, perbandingan, logika, string |
| 4 | `04-input-output.js` | Input & Output | console.log, prompt, konversi tipe data, pola IPO |
| 5 | `05-studi-kasus-lengkap.js` | Studi Kasus Lengkap | 6 studi kasus nyata (BMI, diskon, ATM, dll) |

---

## 🚀 Cara Menjalankan

Jalankan setiap file menggunakan **Node.js** di terminal:

```bash
node 01-pengenalan-sekuensial.js
node 02-variabel-dan-tipe-data.js
node 03-operator.js
node 04-input-output.js
node 05-studi-kasus-lengkap.js
```

---

## 🔑 Konsep Inti

**Pemrograman Sekuensial** = kode dieksekusi **BERURUTAN** dari **ATAS ke BAWAH**, satu baris demi satu baris, tanpa ada lompatan atau pengulangan.

```
Baris 1  →  dijalankan PERTAMA
Baris 2  →  dijalankan KEDUA
Baris 3  →  dijalankan KETIGA
...dan seterusnya
```

---

## 📋 Pola IPO (Input - Proses - Output)

Pola dasar pemrograman sekuensial:

1. **INPUT** → Menerima/menyiapkan data
2. **PROSES** → Mengolah data menggunakan operator
3. **OUTPUT** → Menampilkan hasil ke layar
